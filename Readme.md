# Ethereum To-Do List

This project is a decentralized to-do list application built on the Ethereum blockchain. It allows users to add, complete, and manage tasks in a secure and transparent manner using smart contracts.

## Features

- Add tasks to the to-do list.
- Mark tasks as completed.
- Store tasks securely on the Ethereum blockchain.
- Fully decentralized and transparent.

## Prerequisites

To run this project, you need the following installed:

- [Node.js](https://nodejs.org/)
- [Truffle](https://trufflesuite.com/)
- [Ganache](https://trufflesuite.com/ganache/)
- [MetaMask](https://metamask.io/) browser extension

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/eth-todo-list.git
    cd eth-todo-list-master
    ```

2. Install dependencies:
    ```bash
    npm install
    ```

3. Compile the smart contracts:
    ```bash
    truffle compile
    ```

4. Migrate the smart contracts to the blockchain:
    ```bash
    truffle migrate
    ```

5. Run the development server:
    ```bash
    npm start
    ```

## Usage

1. Open the application in your browser.
2. Connect your MetaMask wallet to the application.
3. Add tasks to the to-do list.
4. Mark tasks as completed when done.

## Project Structure

- `contracts/`: Contains the Solidity smart contracts.
- `migrations/`: Deployment scripts for the smart contracts.
- `src/`: Frontend code for the application.
- `test/`: Test cases for the smart contracts.
